Codex Usage Widget v0.6.0

双击 GPTUsageWidget.exe，或使用桌面的“GPT Usage Widget”快捷方式启动。

- 每 5 秒自动刷新今日 Token、5 小时额度与周额度。
- 窗口可分别调整宽和高，缩小时会依次隐藏次要模块，最小矩形只显示今日 Token。
- 宽、高均达到矩形下限后继续缩小，才会切换为圆形额度球。
- 圆球可等比例缩放；内环代表 5 小时额度，外环代表周额度，中心数字显示两者中较低的剩余比例。
- 鼠标悬停圆球时会分别显示两个额度窗口的重置日期。
- 双击窗口可在圆球和标准面板之间快速切换。
- 顶部 CN/EN 可切换中英文；外观按钮可在自动、浅色、深色之间循环。
- 右键菜单可直接选择外观模式和五种强调色，程序会记住选择；自动模式会跟随 Windows 应用颜色设置。
- 尺寸、悬停和颜色切换采用短促缓动；如果 Windows 已关闭动画效果，程序也会停用这些动效。
- 拖动窗口空白区域可以移动。
- PIN 切换置顶，X 首次点击会询问“彻底结束程序”或“最小化至后台”。选择会被记住，也可在右键菜单的“关闭行为”中修改。
- 选择“最小化至后台”后，任务栏图标会隐藏，程序继续刷新并驻留在 Windows 系统托盘；双击托盘图标可恢复窗口。
- 如果需要真正退出程序，请在右键菜单中选择“彻底结束程序”。
- 圆球顶部有低存在感的展开箭头，鼠标移入时才会提亮，不会遮挡双圆环。
- 圆球模式下右键可刷新、切换尺寸、切换置顶、修改外观或退出。
- 只读取本机 Codex 会话文件，不需要 API Key，也不会联网。

如需直接以圆球启动，可运行：GPTUsageWidget.exe --compact
